# Contributing

The best contributions are rules that came from a real injury. If you add a rule, tell the story: what broke, what it cost, and what the rule would have caught.

- One idea per pull request.
- Plain words. If a new builder can't follow it on first read, rewrite it.
- No em dashes (house style).
- Files under `claude-code/dot-claude/hooks/ecc/`, plus the ECC parts of the three agent files and the polish skill, are vendored from ECC. Send fixes to those upstream at https://github.com/affaan-m/ECC.
